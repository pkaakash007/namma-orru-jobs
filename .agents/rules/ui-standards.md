# UI Design & Iconography Rules

## 1. Strictly Forbidden Symbols & Icons
- **DO NOT USE `Sparkles` or `Sparkle` icons** from `lucide-react` or any other icon library.
- **DO NOT USE `✨` (sparkle emoji)** anywhere in user-facing text, toasts, labels, badges, or headers.
- **DO NOT USE AI gimmick icons** like magic wands (`Wand2`, `Wand`) or robot avatars for human platform features.

## 2. Icon & Design Standards
- Keep the design clean, human, and Apple iOS-inspired.
- Use purposeful, professional, standard icons:
  - Jobs & Career features: `Briefcase`, `Building2`
  - Search & Discovery: `Search`, `SlidersHorizontal`
  - Verified / Extracted Skills: `CheckCircle2`, `Check`
  - Resumes & Profiles: `FileText`, `User`
- All status indicators and spinners should use clean, standard CSS spinners (`animate-spin rounded-full border-2 border-orange-500 border-t-transparent`) rather than spinning sparkles.
